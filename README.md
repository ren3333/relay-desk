# 拾额 · Relay Desk

拾额是一个在 Windows 本机运行的模型网关。把自己在各个公益站的 API 地址、密钥和模型填入拾额后，DSH 可以通过一组本机地址和密钥使用这些模型。

**[下载 Windows x64 最新版](https://github.com/ren3333/relay-desk/releases/latest)**　·　[阅读 1.1.5 中文指南](https://github.com/ren3333/relay-desk/releases/download/v1.1.5/RelayDesk-1.1.5-guide-zh-CN.pdf)

## 第一次使用

1. 从发行页下载文件名以 `windows-x64.zip` 结尾的压缩包，选择「全部解压」，双击「拾额 Relay Desk.exe」。
2. 在浏览器打开的本机管理页进入「站点目录」，查看注册条件和领取方式。注册后，到站方控制台取得自己的模型密钥。
3. 在「接入与路由」填写站点地址、密钥，读取并添加所需模型，勾选「启用此站点的模型路由」后保存。
4. 打开「DSH 接入说明」，将本机地址、访问密钥和统一模型名复制到 DSH，协议选 OpenAI Chat Completions。

## 日常使用

- **合并模型与切换站点**　把不同站点的模型映射到同一个名称，设置优先级。当前站明确报告额度耗尽时，拾额会尝试下一个已启用的站点。
- **领取额度**　「一键签到」适用于已配置个人访问令牌且支持自动签到的 New API 站点。需要人工验证或群内操作时，在该站的「领取方式」查看步骤。
- **添加站点**　可以自行添加，或使用软件内的 JSON 模板批量导入公开信息。

每位使用者自行注册站点、领取额度和配置密钥。密钥保存在当前 Windows 用户的本地加密资料中。模型请求会发送给实际承接调用的站点，接入前请查看它的用途与隐私说明。站点开放时间、额度和模型权限以站方当期规则为准。
